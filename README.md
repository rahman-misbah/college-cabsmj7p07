# AI/ML Lab

Implementation of the laboratory exercises for **CABSMJ7P07 — Artificial Intelligence and Machine Learning**.

This repository contains the work completed throughout the 14-week laboratory, along with reusable implementations of algorithms, data structures, and abstractions developed during the course.

## Structure

```text
.
├── algorithms/          # Reusable algorithm implementations
├── data_structures/     # Reusable data structures
├── models/              # Base and domain models
├── week_1/              # Week 1 activities
├── week_2/              # Week 2 activities
├── week_3/              # Week 3 activities
├── ...
├── week_14/             # Week 14 activities
├── Lab Manual.pdf
└── README.md
```

## Approach

The repository is developed incrementally alongside the laboratory work. Common concepts are extracted into reusable components where appropriate, while individual activities remain self-contained and easy to understand.

For example, the state-space search exercises introduced reusable abstractions for **states, problems, and solvers**, allowing algorithms such as BFS and DFS to be applied to different problem domains.
